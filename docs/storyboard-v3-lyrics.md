# '십자가의 전달자' 오프닝 영상 v3 — 가사가 배어든 기승전결 (60초)

이 곡의 가사는 대부분 바울 자신의 고백이다. 장면마다 가사 한두 줄을 큰 자막으로, 그 고백의 출처인 바울 서신 장절을 작은 금색 글씨로 붙였다. 회중은 영상 직후 특송에서 같은 문장을 다시 듣는다. 마지막에 첫 가사가 되돌아올 때는 고백하는 사람이 바울이 아니라 캠퍼스의 청년들이다.

| 막 | 시간 | 장면 | 큰 자막 (가사) | 작은 자막 |
|---|---|---|---|---|
| **기** 부르심 | 0–6초 | 다메섹 가는 길 | 죄인 중에 괴수 | 디모데전서 1:15 |
| | 6–14초 | 하늘의 빛에 엎드러짐 | 난 지극히 작은 자 / 무익한 날 부르셔서 | 에베소서 3:8 |
| **승** 보내심 | 14–20초 | 금빛 새벽 항해 | 간절한 기대와 소망 / 부끄럽지 않게 | 빌립보서 1:20 |
| | 20–25초 | 폭풍과 파선 | 어디든지 가리라 / 주 위해서라면 | 고린도후서 11:25 |
| | 25–31초 | 빌립보 감옥 | 내 몸에 밴 십자가 / 그 보혈의 향기 | 갈라디아서 6:17 |
| **전** 십자가 | 31–37초 | 밀레도 작별 | 살아도 주를 위해 / 죽어도 주를 위해 | 로마서 14:8 |
| | 37–42초 | 로마 옥중서신 | 사나 죽으나 난 주의 것 | 로마서 14:8 |
| | 42–44초 | 암전, 침묵 | 십자가의 능력 / 십자가의 소망 | 고린도전서 1:18 |
| | 44–50초 | 갈보리, 48초에 빛 | 내 안에 주만 사시는 것 | 갈라디아서 2:20 |
| **결** 전달 | 50–56초 | 금빛 새벽 캠퍼스 선교 | 무익한 날 부르셔서 / 십자가 전케 하셨네 | 오늘, 캠퍼스에서 |
| | 56–60초 | 제목 | **십자가의 전달자** | 로뎀청년회 |

- 색의 흐름: 붉은 노을(기) → 금빛 새벽(승의 시작) → 폭풍과 어둠 → 붉은 갈보리(전) → 금빛 새벽(결). 3번과 9번의 같은 금빛이 "보내심"이 오늘로 이어짐을 보여준다.
- 음악: `video/cross-bearer/src/music.py`. 6초 빛의 충격음, 20–25초 번개 컷마다 북, 25–31초 허밍, 42–44초 침묵, 48초 정점.
- 장절은 가사 내용의 출처로 붙인 것이다. 상영 전에 본문과 대조해 확인할 것.
- "내 몸에 밴"은 맞춤법(배다)에 따랐다. 악보 표기가 다르면 `scenes.mjs`에서 바꾼다.

# v8 — 일러스트 중심, 간결·직관 (편 A·B, 30초·15초)

## Context
- 사용자 피드백(v7.3 시안): "좀 더 간결하면서도 직관성 있게", "구도·영상미가 너무 안 좋다", "휴대폰 씬도 아다리가 안 맞는다".
- 원인:
  1. **산만함:** 30초에 세계가 7개(버스·채팅·책상·부엌·계단·엔드카드…)라 메시지가 흩어진다.
  2. **합성 어긋남:** 생성 사진 속 기울어진 폰에 HTML UI를 억지로 넣고 2.4배 확대해 각도·해상도·빛이 맞지 않는다.
  3. **구도:** 사진은 레이아웃을 모르고 생성됐고, 글자는 남는 자리에 얹혔다.
- 사용자 결정: **일러스트 중심**, 텍스트는 직관적·간결하게. 장면 수는 늘어지지 않게 조정.
- 유지: 랜딩 기반 레이아웃 시스템(04 문서 부록 D: 왼쪽 정렬 x=84, 아이브로→리드→헤드→본문, 랜딩 팔레트), 엔드카드 CTA 문구(시청자 득 중심, "무료" 없음, 버튼 모양 없음), BGM(편 A Alex 130 BPM / 편 B NastelBom 120 BPM), 컴플라이언스(00-brief).

## 1. 원칙
- **한 장면 = 한 그림 + 한 문장.** 30초 4장면, 15초 3장면. 장면당 헤드라인 ≤2줄(줄당 ≤8자 권장), 보조 ≤1줄.
- **그림을 레이아웃에 맞춰 그린다.** 모든 일러스트는 "위 40%는 비어 있는 크림 종이(글자 자리), 아래 60%에 주제"로 생성한다. 글자를 그림 위에 얹지 않고, 그림이 비워 둔 자리에 놓는다.
- **합성 금지.** 그림 속 화면·종이에 UI나 글자를 끼워 넣지 않는다. 그림 속 폰·노트북 화면은 빈 화면 그대로 둔다.
- **모션은 최소.** 장면 안: 그림 푸시 1.00→1.05(장면 전체, `power2.inOut`) + 글자 등장 1회(단어별 blur 6→0, 67ms 간격). 장면 전환: 다운비트 하드컷 2번 + 원인 있는 전환 1번(편 B의 골드 서명선이 다음 장면을 여는 와이프). 엔드카드는 착지 후 2.5초 이상 정지.

## 2. 일러스트 스타일 (GPT/Codex `$imagegen`, ClaraMuz)
- **스타일 테스트를 먼저 한다:** 같은 장면(편 A 훅)을 두 스타일로 1장씩 만들어 사용자에게 보여주고 고르게 한다.
  - S1 "에디토리얼 구아슈": 따뜻한 무광 구아슈 질감, 부드러운 형태, 종이 결 노출, 제한 팔레트(크림 #FBF9F4, 샌드 #F3EEE3, 갈색골드 #7D6233, 남색 #0B1A33, 잉크 #161616).
  - S2 "라인 + 평면색 리소": 가는 잉크 선 + 평면색 2~3도, 리소 인쇄 질감, 같은 팔레트.
- 공통 금지: 읽히는 글자·숫자·로고, 정부·법원 휘장, 3D/광택 렌더, 그라데이션 하늘, 과한 디테일, 기괴한 손. 인물은 얼굴을 단순화하거나 뒷모습·옆모습.
- 고른 스타일의 첫 장을 `-i` 참조 이미지로 넘겨 나머지 장을 같은 스타일로 생성한다. 해상도는 1080×1920 이상 원본(확대 ≤1.1배).
- 파일: `reels/naver-clip/_shared/img/ill/A-1-hook.png` 식. 리드가 한 장씩 열어 검수(글자 없음, 손, 위 40% 빈 공간, 스타일 일관성).

## 6. 작업 순서
1. **스타일 테스트** 2장 생성(Codex) → 리드 검수 → 사용자에게 보내 선택 받기. (게이트)
2. 고른 스타일로 편 A 3장·편 B 3장 + 계단 띠 1장 생성(참조 이미지로 일관성) → 리드 검수, 불합격 재생성.
3. 빌드: `reels/naver-clip/ask-ai/`(편 A), `reels/naver-clip/signature/`(편 B)의 장면 파일을 4장면 구조로 다시 쓴다. 재사용: 랜딩 레이아웃 CSS·락업·티커·체크(ask-ai `compositions/world.html` v7.3), 오디오(`tools/make_audio.py`), 측정·검증 도구(`measure_frames.cjs` 왼쪽 정렬 체크, `gapscan.py`, `verify_cuts.py`, `audio_check.py`), 편 B 서명 SVG 경로(signature `tools/build.py`). 폰 합성(`compositions/phone.html`)은 삭제.
4. 정지 시안(장면마다 착지 1장 + 전환 직후 1장, 30초·15초) → 리드가 모두 직접 확인 → 사용자에게 전송. (게이트)
5. 렌더 4편 → 검증 → 커밋·푸시 → 전송.

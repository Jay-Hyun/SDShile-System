# 광고 개선안 v6 — 편 분리(청년 / 재취업) · 혜택 명확화 · CTA 단일화 · 사운드 교체

## 0. 왜 바꾸나 (평가 요약)
- 클릭 욕구: 훅은 강함(6/10). 1번 서명 메타포는 무엇을 얻는지 늦게 보인다.
- 구매 욕구: 낮음(3~4/10). 기간·학습 방식·지금 해야 할 이유가 광고 안에 없다.
- 타깃: 한 편이 두 타깃을 동시에 노린다. 편마다 한 타깃으로 쪼갠다.
- 게재 리스크: 뉴스 속보 BGM은 교육 광고 신뢰를 해칠 수 있어 교체한다.

## 1. 편 분리
| 편 | 타깃 | 기반 | 훅 방향 |
|---|---|---|---|
| **A. 청년** (20~30대 직장인·취준) | 학력 장벽 때문에 이직·지원이 막힌 사람 | 5번 「AI에게 물었다」 구조 유지 | 질문 자체: "전문대 나왔는데, 퇴근하고 법 공부 할 수 있을까?" |
| **B. 재취업** (40~50대) | 경력은 있는데 학력 칸에서 멈춘 사람 | 1번 「마지막 서명」 장면 재사용 | "15년 경력. 이력서 첫 줄에서 멈췄습니다." (가상 인물, 연출 표기) |

- 두 편 모두 **같은 슬로건**: 「책임지는 자리로, 지금 있는 자리에서.」
- 두 편 모두 **같은 CTA 한 개**: 「내 학점으로 남은 기간, 무료로 진단받기」

## 2. 혜택 명확화 — 팩트 목록 추가
랜딩 원문에 있는 내용만 추가한다(https://policecyber.iwinv.net/). 광고주 확인 전까지 자막에 "랜딩 기준" 표기 가능.
- 퇴근 후·주말에 수강 (랜딩: "퇴근 후·주말에 들어요")
- 고졸·전문대졸·대졸 모두 시작 가능 (랜딩: "고졸·전문대졸·대졸 모두 시작할 수 있어요")
- 이미 딴 학점이 있으면 기간·비용을 줄일 수 있음 (랜딩: "기간·비용을 줄일 수 있어요". 얼마나 줄어드는지는 말하지 않는다)

금지(추가 포함): 기간 숫자(○개월), 가격, "합격·취업 보장", "누구나 지원 자격 확정". 기간은 "학점에 따라 다르다"로만 쓴다.

## 3. CTA 단일화
- 주 CTA: **「내 학점으로 남은 기간, 무료로 진단받기」** (버튼 1개, 골드). "무료"는 진단에만 쓴다.
- 전화 070-4006-7128(평일 10–18시)은 엔드카드 하단 보조 한 줄.
- 기존 "내 학력으로 몇 학기? 1:1로 확인하세요" 유도 줄은 버튼 문구로 흡수한다(중복 제거).
- 근거 리스트(✓ 3줄)는 유지하되 4줄 이하, 한 줄 한 뜻.

## 4. 편 A — 청년 (30초 구성)
| 구간 | 화면 | 자막·내레이션 |
|---|---|---|
| 0–3s | 채팅 입력창에 질문이 타이핑 | 질문: "전문대 나왔는데, 퇴근하고 법 공부 할 수 있을까?" |
| 3–9s | AI 답변 말풍선(연출, 가상 UI) | "반복 업무는 자동화되고, 최종 판단과 법적 책임은 사람이 맡게 됩니다." (※ 연출된 가상 대화) |
| 9–14s | 상담사 연결 | "이건 책임지고 답할 분께 넘길게요 🙂" |
| 14–21s | 상담사 답변(사람) | "퇴근 후·주말에, 100% 온라인으로 들을 수 있어요." → "이미 딴 학점이 있으면 기간·비용을 줄일 수 있어요." |
| 21–25s | 근거 3줄 | ✓ 100% 온라인, 출석 없이 / ✓ 교육부장관 명의 법학사 / ✓ 전문대 졸업이면 60학점부터 |
| 25–30s | 슬로건 → 주 CTA 버튼 → 전화 보조 | 「책임지는 자리로, 지금 있는 자리에서.」 / 「내 학점으로 남은 기간, 무료로 진단받기」 |

- 15초: 질문 → 상담사 답(퇴근 후·주말, 100% 온라인) → 주 CTA. 근거 리스트는 빼고 답변에 한 줄로 압축.

| 구간 | 화면 | 자막·내레이션 |
|---|---|---|
| 0–3s | 이력서 학력 칸 클로즈업(빈 칸 커서) | "15년 경력. 이력서 첫 줄에서 멈췄습니다." |

| 16–23s | 퇴근 후·주말 수강, 이미 딴 학점 반영 | "퇴근 후·주말에, 100% 온라인으로. 이미 딴 학점이 있으면 기간·비용을 줄일 수 있어요." |
| 23–27s | USP | "국내 유일* 100% 온라인 법학사" / "교육부장관 명의 · '법학 전공' 표기" |
| 27–30s | 슬로건 → 주 CTA → 전화 보조 | 「책임지는 자리로, 지금 있는 자리에서.」 / 「내 학점으로 남은 기간, 무료로 진단받기」 |

- 15초: 훅 → 서명 → 주 CTA. 학점 설명은 한 줄.
- 가상 인물 표기: 훅 화면에 "가상 인물 · 연출" 배지 상시 표시.

## 6. 사운드 — 장르: 모던 시네마틱 팝-일렉트로닉 (적당히 웅장 + 청각 훅)
- 제거: Breaking News 두 곡(속보 장르라 광고 신뢰를 해침). 너무 잔잔한 앰비언트는 스크롤을 못 멈추고, 풀 오케스트라 트레일러는 과하게 웅장해서 제외.
- 장르: **모던 시네마틱 팝-일렉트로닉(코퍼레이트 인스파이어링 계열)** — 짧고 기억에 남는 **멜로디 훅(플럭·피아노 모티프)** + 타이트한 킥/클랩/스냅 + 가벼운 스트링 레이어 + 깔끔한 베이스.
- 템포: 100~118 BPM. 1~2초 안에 훅 모티프가 먼저 들려야 한다(청각 후킹).
- 웅장함은 "한 방"만: 훅 직후와 반전/엔드카드 시점에 가벼운 임팩트·라이저 한두 번. 계속 몰아치지 않는다. 대규모 오케스트라 히트, 트레일러식 롱 라이저, 강한 서브 폭발은 쓰지 않는다.
- 고급감: 신스는 둥글고 짧게, 스트링은 뒤에서 받쳐 주기만, 리버브는 짧게.
- 청각 디테일: 펜·종이·탭 실제 샘플을 짧게, 훅 타이밍에 맞춘다. 합성 효과음은 쓰지 않는다.
- 편 A/B: A = 피아노·플럭 모티프 중심(질문·답의 경쾌한 리듬), B = 스트링 레이어를 조금 더 얹은 버전(재기 서사). 같은 계열 안에서 음색만 다르게.
- 음악은 끊지 않는다. 마스터 −15 LUFS, 트루피크 ≤ −1 dBTP.
- 후보 검색어(라이선스·BPM 확인 필수): "inspiring corporate pop", "modern cinematic pop electronic", "motivational pluck piano beat", "technology corporate upbeat".

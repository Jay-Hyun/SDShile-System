# '십자가의 전달자' 오프닝 영상 v2 — 바울의 여정 (60초, 시네마틱)

v1(벡터 실루엣 애니메이션)은 폐기 방향. v2는 **생성 이미지 10장 + 느린 카메라 움직임 + 자막 + 창작 음악**으로 만든다.

## 연출

- **한 사람의 길.** 여러 증인을 훑지 않고 바울 한 사람을 따라간다. 핍박자가 빛에 쓰러지고, 바다를 건너고, 매 맞고, 갇히고, 끝까지 달린다.
- **마지막 질문.** 로마 감옥에서 "무엇이 그를 달리게 했는가"로 끊고, 갈보리로 넘어간다. 답은 바울 자신의 고백(갈 2:20)이다.
- **그림.** 영화 스틸 같은 회화풍 매트 페인팅. 2.39:1 레터박스, 명암 대비 강하게, 금빛 역광. 인물은 뒷모습이나 실루엣만. 예수님은 먼 실루엣으로만.
- **움직임.** 장면마다 느린 줌이나 팬 하나, 먼지와 빛 입자, 장면 사이는 빛 번짐 전환.
- **자막.** 화면 아래 한 줄, 개역개정. 제작 전에 본문과 한 글자씩 대조한다.

이야기·카피·컷 순서는 이전 판과 같고, **룩·모션·음악 이음**만 바꿨다. 이전 판(흔들림·플래시·스프링·키보드)은 git 히스토리(5fb15d1)에 있다.

## 룩 (02 §1–3, §7-1, §7-2)
- 중심축 x=540 하나. 말풍선·버튼은 컬럼 x 120–960(840px) 전폭, 가운데 글자는 전폭 컨테이너 `text-align:center`. 음수 자간의 끝 여백은 `padding-right`로 되돌려 박스 중심 = 글자 중심.
- 크기 4단계: Display 144/700/−0.045em/1.05(훅·USP), Head 88/600/−0.03em/1.15(고민 중·사람의 답·CTA 문장·슬로건·전화 번호), Body 44/500/−0.01em/62px(챗·로고·버튼·리스트·유도), Small 26/400(배지·고지).
- 색: 챗 = Paper #F7F6F2, AI 말풍선 톤 #EAE7DF, 입력 독 #EEEBE4(입력창 알약은 Paper), 사용자 말풍선 Ink #0E1116, 보조 #5F6368. 브랜드 = Navy #0B1A33 단색, 풋터 필드 #102545(한 톤), 보조 #9AA0A6. 강조 Gold #B8955A 하나(언더라인·'국내 유일'·60·1:1·체크·유도·CTA 버튼, 측정 4.83% 이하). 그라데이션·그림자·블러·그레인·파티클 없음.
- 화자는 좌우가 아니라 **색**으로 가른다(사용자 = Ink 면, AI = 톤 면). 🙂는 글자와 같은 잉크의 인라인 SVG.
- **밀도(§7-2)**: 블록 사이 틈 ≤ 140px, 가장 큰 빈 띠 ≤ 15%. 챗은 헤더 아래(y 348)와 입력 독(y 1378) 사이를 채운다. 쌓인 높이가 짧으면 위·아래 틈을 같게 나누고(훅 프레임: 헤더·제목·질문·AI 말풍선·독 사이가 모두 ≈136), 길면 독 위 16–24px 에 붙여 위가 헤더 밑으로 스크롤된다. 제목→첫 질문 틈은 훅에서 136, 답이 자라기 시작하면 60 으로 좁아진다(제목만 한 번 더 움직인다). 어두운 장면은 풋터 필드, 챗은 입력 독이 바닥을 채운다.
- **로고 락업**: 금색 심볼(56×62) + 기관명(Body 44/600), 간격 18px, 한 줄, 락업 전체 중심 x=540, y 300. 모든 브랜드 프레임(30s C7–C9, 15s C5–C6)에서 같은 자리에 보인다(`#br-logo-row`).

## 모션 (02 §4–5)
- 마스크 라인 상승(800ms, .16,1,.3,1, 줄 사이 90ms) · UI 등장(320ms, 16px) · 퇴장(300ms) · 컬럼 글라이드(450ms in-out) · 언더라인 선 드로잉(1100ms) · 숫자 롤(700ms) · 오프닝 윈도우(1200ms). 흔들림·플래시·스프링·바운스·글자 타이핑 없음.
- 챗 메시지는 줄 단위로 통째로 나온다. 아래 입력창에 "나 전문대 나왔는데 → (는데 지움) → 고 회사 다니는데, → 법 공부 할 수 있어?" 네 덩어리가 들어가고(둘째 줄에서 입력창이 위로 한 줄 자란다. 독은 처음부터 그만큼 열려 있어 대화는 움직이지 않는다), 전송하면 입력창은 비고 질문은 대화에 Ink 말풍선으로 올라간다.
- **로딩 개그**: 음악은 끊기지 않고 흐른다(무음·페이드·필터 없음). 질문이 도착하는 순간 컬럼이 한 번에 올라가고, 마지막 말풍선과 독 사이 가운데에 Head 88 "고민 중… → 아직 고민 중… → 음…"이 같은 길이(≈0.77 s)로 제자리 크로스페이드(200ms)한다. 15s 는 "고민 중…" 하나(1.6 s). 답은 음악 이음새의 다운비트(R)에 뜬다.
- 시그니처: [상담사 연결](840×120 Navy 알약)이 clip-path로 열려 화면 전체가 상담 화면이 된다. 1200ms in-out의 가장 빠른 중간점이 원곡 B섹션 크래시(30s 18.236, 15s 8.638)에 온다.
- 카메라: 컷마다 한 번 1.00 → 1.03 선형 푸시(챗은 시그니처 버튼 중심, 브랜드는 바뀌는 글 묶음만 — 컷에서 로고·버튼·전화는 움직이지 않는다).

## 사양과 다른 점
- 챕터 시각을 다운비트로 다시 잡음: 30s C2 3.839(사양 3.0) / C3 7.678(7.0) / C4 9.598(10.0) / 🙂 답 14.397(15.0) / C7 18.236(18.0) / C8 20.155(21.0) / C9 22.075(23.5). 15s C2·C3 은 훅 3초와 🙂 답 사이라 읽는 속도에 둔 장면 안 등장(3.0 / 4.9). "고민 중…"의 시작은 사용자의 전송(30s 11.98)을 따른다(다운비트가 아님).
- 이전 판 대비 이동: 음악 이음새를 정수 박자로 바꿔 R 이후 모든 장면이 30s −0.24 s, 15s +0.14 s 움직였다. 30s 엔드 시퀀스 7.925 s(+0.24), 15s 엔드카드 2.52 s(−0.18).
- 배지 교체는 열리는 창이 위쪽을 덮은 뒤(30s 18.57, 15s 8.97). '국내 유일' 각주·보장 금지 고지는 크래시(18.236 / 8.638)부터 끝까지. "※ 연출된 가상 대화입니다"는 첫 AI 말풍선 아래 대신 입력 독 안 입력창 바로 아래(Small 26)에 **처음부터** 버튼이 열릴 때까지 고정(첫 프레임에 AI 말풍선이 이미 있으므로 사양 C2 시작보다 빠른 것은 상위 호환).
- 챗 UI 색은 사양의 그레이+틸 대신 02의 Paper·톤·Ink·Navy + 골드(실존 AI 브랜드와 닮지 않음). 앞 문단(사양: 블러로 스쳐 지나감)은 블러 금지라 흐린 색(#5F6368)의 읽히는 두 줄로 두었다. AI 타이핑 말풍선은 사양(1.5초에 등장)과 달리 첫 프레임부터 보인다(훅 프레임의 빈 띠를 없애기 위해).
- 서체 크기는 사양(챗 52/헤드라인 88/고지 28)이 아니라 02 §7-1 네 단계. USP 는 Display 144 세 줄("국내 유일"은 골드, "100% 온라인 / 법학사*"). 슬로건은 Display 로는 한 줄이 840px 을 넘어 Head 88 두 줄, CTA "AI도 넘긴 질문, / 사람이 1:1로 / 답해드려요."는 Head 88 세 줄(두 줄이면 2행이 936px).
- 사람의 답은 말풍선 대신 조판(인용한 내 질문 Body + 답 Head, 60 골드 롤). 상담사 라인 아이콘·손가락·배경 스톡은 쓰지 않는다(02 §6).
- **엔드 시퀀스**: 30s C9·C10 을 22.075–30.0 한 덩어리로. CTA 문장(Head) → 23.994 증거 리스트(골드 체크 + Body, 묶음 가운데·줄 왼쪽 맞춤) → 25.914 슬로건 교체. CTA 트랙(유도 골드·버튼·안내·전화)은 같은 자리에 고정하고 안내 "상담만 받아도 돼요."는 슬로건과 함께. 15s C6 은 슬로건 + 버튼(유도·전화는 C5 부터). 읽기 속도는 `npm run reading` — 엔드 시퀀스 메인 글자 9.2자/초(트랙 포함 13.4).
- 배지·고지 26px 은 02 §7 값(check `text_below_floor` 경고는 의도).
- 내레이션(VO)은 아직 없다. 녹음하면 `<audio>` 트랙으로 넣고 BGM을 덕킹한 뒤 −15 LUFS로 다시 맞춘다 (※ 02 §7-2 는 덕킹을 금하므로, VO 를 넣을 때는 리드와 다시 정한다).

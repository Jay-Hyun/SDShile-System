# 네이버 클립 콘셉트 5 「AI에게 물었다」 — 아트 디렉션 v3.1 (HyperFrames + anime.js v4)

1080×1920, 30fps. 30초(루트)와 15초(`v15/`). 사양: `docs/ads/naver-clip/05-ask-ai.md`, 룩·모션 기준: `docs/ads/naver-clip/02-art-direction.md`(v3 + §7-1 밀도).
이야기·카피·컷 순서·BGM 편집·비트 그리드는 이전 판과 같고, **룩과 모션만** 바꿨다. 이전 판(흔들림·플래시·스프링·키보드)은 git 히스토리(5fb15d1)에 있다.
**엔진은 anime.js v4.5.0 하나뿐이다**(`lib/anime.min.js`, 로컬 번들). GSAP 0건.

## 룩 (02 §1–3, §7-1)
- 중심축 x=540 하나. 말풍선·버튼은 모두 컬럼 x 120–960(840px) 전폭, 가운데 글자는 전폭 컨테이너 `text-align:center`. 음수 자간의 끝 여백은 `padding-right`로 되돌려 박스 중심 = 글자 중심.
- 크기 4단계: Display 144/700/−0.045em/1.05(훅·USP), Head 88/600/−0.03em/1.15(고민 중·사람의 답·CTA·슬로건), Body 44/500/−0.01em/62px(챗·로고·버튼·전화), Small 26/400(배지·고지).
- 색: 챗 = Paper #F7F6F2 바탕, AI 말풍선 톤 #EAE7DF, 입력창 #EEEBE4, 사용자 말풍선 Ink #0E1116, 보조 #5F6368. 브랜드 = Navy #0B1A33 단색, 보조 #9AA0A6. 강조 Gold #B8955A 하나(언더라인·'국내 유일'·60·1:1·CTA 버튼, 화면의 5% 이하). 그라데이션·그림자·블러·그레인·파티클 없음.
- 화자는 좌우가 아니라 **색**으로 가른다(사용자 = Ink 면, AI = 톤 면). 🙂는 글자와 같은 잉크의 인라인 SVG.
- 밀도(§7-1): 대화는 실제 챗처럼 안전 영역 바닥 y 1440에 붙고, 새 줄·새 말풍선이 생기면 컬럼이 위로 밀린다(헤더 아래 y 290에서 잘림). AI 답은 흐린 앞 문단 2줄 + 핵심 2줄 + 예시 줄의 큰 말풍선. 측정한 최장 빈 띠는 프레임 높이의 27% 이하.

## 모션 (02 §4–5)
- 마스크 라인 상승(800ms, .16,1,.3,1, 줄 사이 90ms) · UI 등장(320ms, 16px) · 퇴장(300ms) · 컬럼 글라이드(450ms in-out) · 언더라인 선 드로잉(1100ms) · 숫자 롤(700ms) · 오프닝 윈도우(1200ms). 흔들림·플래시·스프링·바운스·글자 타이핑 없음.
- 챗 메시지는 줄 단위로 통째로 나온다. 아래 입력창에 "나 전문대 나왔는데 → (는데 지움) → 고 회사 다니는데, → 법 공부 할 수 있어?" 네 덩어리가 들어가고(둘째 줄에서 입력창이 위로 한 줄 자라며 대화도 올라간다), 전송하면 입력창은 비고 질문은 대화에 Ink 말풍선으로 올라간다.
- 로딩 개그: 음악이 비트에서 80ms 만에 깨끗이 멈추고(완전 무음, 효과음 없음), 답이 올 자리 가운데에 Head 88 "고민 중… → 아직 고민 중… → 음…"이 제자리 크로스페이드(200ms)로 바뀐다.
- 시그니처: [상담사 연결](840×120 Navy 알약)이 clip-path로 열려 화면 전체가 상담 화면이 된다. 1200ms in-out의 가장 빠른 중간점이 원곡 B섹션 크래시(30s 18.476, 15s 8.5)에 온다.
- 카메라: 컷마다 한 번 1.00 → 1.03 선형 푸시(챗은 시그니처 버튼 중심, 브랜드는 바뀌는 글 묶음만 — 컷에서 로고·버튼·전화는 움직이지 않는다).

## 사양과 다른 점
- 챕터 시각을 다운비트로 다시 잡음: 30s C2 3.839(사양 3.0) / C3 7.678(7.0) / C4 9.598(10.0) / C5 12.477(12.5) / C6 14.637(15.0) / C7 18.476(18.0) / C8 20.395(21.0) / C9 22.315(23.5) / C10 26.154(27.0). 15s C2·C3은 훅 3초와 클린 스톱 사이라 읽는 속도에 둔 장면 안 등장(3.0 / 4.9).
- 배지 교체는 열리는 창이 화면 위쪽까지 덮은 뒤(30s 18.80, 15s 8.83). '국내 유일' 각주·보장 금지 고지는 크래시(18.476 / 8.5)부터 끝까지. "※ 연출된 가상 대화입니다"는 첫 말풍선 아래 대신 입력창 바로 아래(y 1560–1596, Small 26)에 C2부터 버튼이 열릴 때까지 고정(리드 결정).
- 챗 UI 색은 사양의 그레이+틸 대신 02의 Paper·톤·Ink·Navy + 골드(실존 AI 브랜드와 닮지 않음). 앞 문단(사양: 블러로 스쳐 지나감)은 블러 금지라 흐린 색(#5F6368)의 읽히는 두 줄로 두었다.
- 서체 크기는 사양(챗 52/헤드라인 88/고지 28)이 아니라 02 §7-1 네 단계. USP는 Display 144에서 "국내 유일 100%"가 840px을 넘어 골드 Head "국내 유일" + Display "100% 온라인 / 법학사*". 슬로건은 Display로는 한 줄이 840px을 넘어 Head 88 두 줄, CTA "AI도 넘긴 질문, / 사람이 1:1로 / 답해드려요."는 Head 88 세 줄(두 줄이면 2행이 936px).
- 사람의 답은 말풍선 대신 조판(인용한 내 질문 Body + 답 Head, 60 골드 롤). 상담사 라인 아이콘·손가락·배경 스톡은 쓰지 않는다(02 §6).
- 엔드 시퀀스(클라이언트 "비어 보인다"): 30s C9·C10을 22.315–30.0 한 덩어리로. CTA 문장(Head) → 24.234 증거 리스트(골드 체크 + Body, 묶음 가운데·줄 왼쪽 맞춤) → 26.154 슬로건 교체, CTA 유도(골드)·버튼·전화는 처음부터 고정, "상담만 받아도 돼요."는 슬로건과 함께. 15s C6은 슬로건 + "100% 온라인 · 교육부장관 명의 법학사" + CTA 유도 + 버튼(전화는 C5부터). 글자 양이 많아 전체 읽기 속도는 30s 13.8자/초, 15s 22.2자/초(문장·리스트·슬로건만 9.5자/초) — 리드 판단 대상.
- 30s "아직 고민 중…" 0.72 s는 교체식 코믹 비트라 유지. 배지·고지 26px은 02 §7 값(check `text_below_floor` 경고는 의도).
- 내레이션(VO)은 아직 없다. 녹음하면 `<audio>` 트랙으로 넣고 BGM을 덕킹한 뒤 −15 LUFS로 다시 맞춘다.

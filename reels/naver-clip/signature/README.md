# 네이버 클립 콘셉트 1 「마지막 서명」 — v3 아트 디렉션 · anime.js v4 · 마디 컷 (HyperFrames)

1080×1920 · 30fps · 30.0초(프로젝트 루트) / 15.0초(`v15/`). 문구·컷 순서·컴플라이언스는 `docs/ads/naver-clip/01-last-signature.md` 그대로다.
룩과 모션은 `docs/ads/naver-clip/02-art-direction.md`(v3 + §7-1 밀도)를 따른다. 컷은 BGM 마디선(다운비트)에 둔다.
렌더: `renders/last-signature-30s.mp4`, `renders/last-signature-15s.mp4` (내레이션 없음).

## 룩 (v3 / v3.1)
- **축 하나:** 모든 글자는 x=540 중심의 840px 행(`.row`, 좌우 여백 120px)에 가운데 정렬한다. 측정값은 아래 "검증"에 있다.
- **글자 크기 4단계:** Display 144 / Head 88 / Body 44 / Small 26. 서체는 Pretendard GOV 한 패밀리다.
  - 가운데 정렬 줄은 자간의 절반만큼 오른쪽 패딩을 준다. 마지막 글자 뒤에도 붙는 자간 때문에 잉크가 밀리는 것을 상자와 잉크 사이에서 나눈다.
- **색:** Ink #0E1116(C1·C2·C3·C4·C5), Paper #F7F6F2(C1 S2 문서 클로즈업, C7 위쪽 '생성하는 쪽'), Navy #0B1A33(C6 이후 브랜드, 엔드카드).
  - Gold #B8955A는 사람 쪽에만 쓴다: 캐럿, 서명선, '첫 계단', '국내 유일*', 슬로건 밑줄.
  - Red #C8392B는 토스트에만 쓴다.
  - 면은 톤 한 단계 차이로만 나눈다(문서 더미, 서명 칸 패널). 그라데이션·그림자·블러·그레인·파티클은 없다.
- **그림 대신 오브제:** 손·책상·창문·펜 일러스트는 지웠다.
  - 문서는 단색 종이 사각형과 실제 조판한 글줄이다.
  - '그 칸'은 큰 서명 칸(톤 한 단계 위 패널: 선, 캐럿, 아래 캡션)이다.
  - C5 '그 자리'는 프레임 폭의 수평선이다.
  - C7은 Paper/Navy 두 면 분할이다.
- **밀도:** 각 정착 프레임에서 이어진 빈 띠는 프레임 높이의 35% 이하다(`tools/density.py`).

| 퇴장 `LEAVE` | 300ms `(.55,.055,.675,.19)`, 8px + 불투명도 |
| 카메라 `PUSH` | 샷마다 1.00→1.03 선형, 프레임 중심 기준(x=540 유지) |
| 라인 드로잉 `DRAW` | SVG stroke 1100ms `(.76,0,.24,1)`: 서명선, 15초 슬로건 밑줄 |
| 이동·와이프 | in-out `(.76,0,.24,1)`: C5 선 늘이기, C8 Paper 면 와이프 0.9초, 금빛 선 → 슬로건 밑줄 0.8초 |
| 캐럿 `CARET` | 530ms on/off(음악과 무관) |

- 오버슈트·스프링·흔들림·플래시·휩·글리치는 쓰지 않는다. 시그니처 모먼트는 하나다: C6에서 서명 칸을 가로지르는 940px 금빛 서명선.
- **엔진:** anime.js v4.5.0(`lib/anime.umd.min.js`, MIT, 로컬 번들)만 쓴다.
  - 씬마다 `anime.createTimeline({ autoplay: false })`를 하나 만들어 `window.__hfAnime`에 push한다. 위치는 루트 절대 초다.
  - rAF, 타이머, 랜덤은 쓰지 않는다.

## 만들기
```bash
python3 tools/beats.py                                     # beats/source.json (BPM, 비트, 다운비트)
python3 tools/build.py && python3 tools/build.py --variant 15   # 씬 + index.html (+ v15/), beats/cuts*.json(컷·이동·SFX 큐)
python3 tools/make_audio.py && python3 tools/make_audio.py --variant 15   # SFX는 cuts*.json의 큐를 읽는다
python3 tools/subset_font.py /path/PretendardGOVVariable.woff2  # 문구를 바꾸면 다시 실행
npm run check && npm run check:15
NODE_PATH=$(npm root -g) node tools/measure.cjs [--variant 15]  # 중앙 정렬(|Δx|), 글자 크기 집합, 빈 띠 %
npm run render && npm run render:15
python3 tools/verify.py renders/last-signature-30s.mp4 30   # ffprobe, 라우드니스, 컷 대 다운비트, MP4 프레임 중앙 정렬
```
씬 파일과 `index.html`은 빌더가 만든다. 손으로 고치지 말고 `tools/build.py`를 고친 뒤 다시 생성한다.

## 컴플라이언스 메모
- 가상 "문서 도우미"를 모방 없는 순수 타이포로 만들었다. 스파클, 말풍선, 사이드바, 실존 AI 브랜드 요소는 없다.
- 당사자는 갑·을만 쓴다. 사건번호·법원명·휘장·직인·정부 로고는 없다. 브랜드 마크는 `assets/img/mark.svg`(골드 #B8955A)다.
- "무료"는 버튼에만 쓴다. 의자·판사석 이미지는 없다. 레드는 토스트에만 쓴다.

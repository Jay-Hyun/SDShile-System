# 네이버 클립 콘셉트 1 「마지막 서명」 — anime.js v4 · BGM 비트 컷 (HyperFrames)

1080×1920 · 30fps · 30.0초(프로젝트 루트) / 15.0초(`v15/`). 문구·컷 순서·컴플라이언스는 `docs/ads/naver-clip/01-last-signature.md` 그대로 두고, **컷 경계만 BGM 비트에 맞춰 ±0.5초 안에서 다시 잡았다.**
렌더: `renders/last-signature-30s.mp4`, `renders/last-signature-15s.mp4` (내레이션 없음, 스톡 대신 벡터 일러스트)

- **엔진:** anime.js v4.5.0만 쓴다(`lib/anime.umd.min.js`, MIT, 로컬 번들). GSAP은 쓰지 않는다.
  - 씬마다 `anime.createTimeline({ autoplay: false })`를 하나 만들어 `window.__hfAnime`에 push한다. HyperFrames는 모든 anime 인스턴스를 **루트 시간(ms)**으로 seek하므로 씬 안의 위치도 절대 초로 적는다.
  - 루트는 `data-no-timeline`이다(GSAP 타임라인 레지스트리 없음).
  - 랜덤 요소(셰이크, 그레인, 먼지, 불씨)는 모두 `anime.createSeededRandom` 시드로 고정한다.
  - rAF와 타이머는 쓰지 않는다.
- **쓰인 anime 기능:**
  - `stagger`: 문서 줄 채움, 단어 키네틱, 리타이핑
  - `svg.createDrawable`: 서명 밑줄, 금빛 잉크, 데스크 라인, 슬로건 밑줄
  - `spring`: 체크, 버튼, 스플릿 패널, 브랜드
  - `innerHTML` 카운트업: 생성 중 0→99%
  - 시드 랜덤 카메라 셰이크와 그레인(2프레임마다)
- **음악:** `MUSIC.md` 참고. "Breaking News Intro"(Pixabay 527939), 137 BPM. 비트 그리드는 `beats/source.json`, 컷 계획은 `beats/cuts.json`·`beats/cuts-15s.json`에 있다.

## 만들기
```bash
python3 tools/beats.py                                  # beats/source.json (BPM, 비트, 다운비트, 강세, 브레이크)
python3 tools/make_audio.py && python3 tools/make_audio.py --variant 15   # assets/audio/mix-{30,15}s.mp3
python3 tools/build.py && python3 tools/build.py --variant 15             # compositions + index.html (+ v15/)
python3 tools/subset_font.py /path/PretendardGOVVariable.woff2            # 문구를 바꾸면 다시 실행
npm run check && npm run check:15
npm run render && npm run render:15
python3 tools/verify.py renders/last-signature-30s.mp4 30   # ffprobe, 라우드니스, 컷 대 비트 대조 → renders/verify-30s.json, cuts-30s.jpg
```
씬 파일과 `index.html`은 빌더가 생성한다. 손으로 고치지 말고 `tools/build.py`를 고친 뒤 다시 생성한다.

## 고지 레이어 (`legal`, 상시)
- `연출`: 30초 15.349–24.091(C5 S2–C6 끝, 스펙 f465–f719). 15초 9.207–12.261(C6', 스펙 f270–f359).
- 고지 L1·L2: USP와 함께 30초 21.014초부터, 15초 10.519초부터 끝까지 나간다. 24.091초(15초는 12.261초)부터는 밝은 배경이라 먹색으로 바꾼다.
- `[가상 문서 · 예시]` 워터마크는 모든 문서에 있다. '국내 유일*' 각주(L2 MASTER)를 쓴다.

## 컴플라이언스 메모
- 가상 "문서 도우미" UI다(문서 글리프 아이콘, 상단 입력 스트립). 스파클, 말풍선, 사이드바, 하단 입력창은 없다.
- 문서 3장 모두 `[가상 문서 · 예시]` 워터마크를 달았다. 당사자는 갑·을만 쓰고, 사건번호·법원명·휘장·직인은 없다.
- 정부 로고는 쓰지 않았다. 브랜드 마크는 `assets/img/mark-gold.svg`이다.
- "무료"는 버튼에만 쓴다. 의자·판사석 이미지는 없다.
- 레드는 경고 토스트에만 쓴다.

## 남은 일 — 내레이션(VO)
VO는 아직 녹음 전이다. 대사는 스펙 §7 그대로이고, 샷 경계가 위 표처럼 ±0.3초 안에서 움직였을 뿐 7자/초 한도 안에 있다.
녹음한 뒤 `<audio id="vo">`를 `index.html` 템플릿(빌더)에 추가하고, `make_audio.py`에서 VO 구간 음악을 약 −8dB 덕킹한 다음 −15 LUFS로 다시 맞춘다.

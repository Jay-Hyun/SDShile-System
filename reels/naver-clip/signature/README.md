- 밀도(§7-2): 정착 화면의 가장 큰 빈 띠 ≤15%, 블록 틈 ≤140px. 어두운 장면 하단에 한 톤 다른 풋터 필드(y 1580–1920), 고지는 y 1494–1563.

## 만들기
```bash
python3 tools/build.py && python3 tools/build.py --variant 15        # 씬 + index.html (+ v15/), beats/cuts*.json
python3 tools/make_audio.py && python3 tools/make_audio.py --variant 15   # assets/audio/mix-{30,15}s.mp3

npm run check && npm run check:15
NODE_PATH=$(npm root -g) node tools/measure.cjs [--variant 15] --at ...   # Δx, 글자 크기, 빈 띠, 블록 틈, 읽는 속도
npm run render && npm run render:15
python3 tools/verify.py renders/last-signature-30s.mp4 30            # ffprobe, 라우드니스, 컷 대 비트, 렌더 픽셀 스캔, 디코드 프레임 중앙 정렬
```

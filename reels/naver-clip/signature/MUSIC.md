- 곡: **"Breaking News Intro"** — kornevmusic, Pixabay ID **527939** (사용자 제공 파일 `kornevmusic-breaking-news-intro-527939.mp3`, 프로젝트 사본 `assets/music/source.mp3`).
- 원본: 65.3초, 44.1kHz 스테레오, 통합 −8.0 LUFS, 트루피크 +0.7 dBTP(클리핑 있음).
- **라이선스 확인은 사용자 몫이다.** Pixabay Content License 조건(광고 사용, 크레디트 필요 여부)은 집행 전에 사용자가 확인한다. 이 문서는 출처만 기록한다.
- 합성 음악은 넣지 않았다. 효과음은 깨끗한 톤 두 가지(토스트 사인 단음, 펜 우드 톤)뿐이다.

## 비트 분석 (`tools/beats.py` → `beats/source.json`)
- numpy + ffmpeg. 로그 스펙트럼 플럭스(hop 256 @ 22.05kHz)를 onset 엔벨로프로 쓰고, 자기상관으로 템포를 잡았다. 고정 템포 그리드의 위상은 onset 합으로 맞췄고, 각 비트는 ±35ms 안의 onset 피크로 보정했다. 다운비트는 4박 위상 중 저역(<150Hz) onset이 가장 큰 위치다.
- **137.02 BPM**(비트 0.4379초), 다운비트 위상 0. 곡 구조:
  - 0–1.78초: 라이저 인트로(저음량)
  - 1.78초~: 풀 비트. 8박(3.5초)마다 강세, 16박마다 큰 히트(21.04 / 28.05 / 35.05 / 42.06초 …)
  - **15.8–20.6초: 드럼이 빠지는 빌드**. 17.98–18.42초에 −12dB 브레이크가 있고, **21.04초에 곡 최대 히트(onset 1.00)**가 온다.
  - 63.5초~: 아웃트로 페이드

- 마스터: 볼륨 → 192kHz 오버샘플 리미터(−2.5dBFS) → 48kHz MP3 256k.
  - 측정 `assets/audio/mix-30s.mp3` −14.9 LUFS / TP −4.4 dBTP, `mix-15s.mp3` −15.0 LUFS / TP −4.8 dBTP.
  - 렌더 MP4(AAC, v3): 30초 −15.0 LUFS / TP −4.9 dBTP, 15초 −15.1 LUFS / TP −4.6 dBTP (`tools/verify.py`).
- 덕킹을 지워 LRA가 줄었다. 수치는 렌더 검증 값(README "검증")에 있다.
- **SFX (4차, 편당 2개):** 노이즈 없는 깨끗한 톤만 쓴다. 시각은 그림에서 온다: `tools/build.py`가 `beats/cuts*.json`의 `sfx`에 쓰고, `make_audio.py`가 읽는다. 소리는 그림보다 1프레임 늦게 놓는다.
  - 토스트 "이 항목은 생성할 수 없습니다": 330Hz 사인 단음 0.28초(어택 6ms, 감쇠 τ 90ms). 주변 음악 RMS보다 −20dB. 30초 8.88초, 15초 3.28초.
  - 펜 "톡": 1050Hz와 620Hz 우드 톤(어택 2ms), 클릭 노이즈와 저역 쿵은 없다. 주변 음악 RMS보다 −18dB. 곡 최대 히트에 얹는다. 30초 19.261초, 15초 10.066초.
  - 생성 클릭, 버튼 틱, 휩, 스와이프, 체크 틱은 없다.
- **고역 확인(10kHz 이상 에너지, 전체 대비)**: 이전 렌더 / 새 믹스 / 원곡 발췌
  - 30초 10.1–14.0초: −72.0 / −37.3 / −37.2 dB
  - 30초 10–19초: −34.6 / −31.6 / −31.7 dB
  - 15초 4.8–9.2초: −67.5 / −29.2 / −29.2 dB
  - 먹먹함이 사라지고 원곡의 톤으로 돌아왔다.
- 들어서 확인하지는 않았다. 측정만 했다(ebur128, 컷·비트 대조).

# 경찰복지사이버평생교육원 릴스 — 시험지(기출변형) 버전

1080×1920, 30fps, 28초. 메인 릴스(`../policecyber`)와 같은 메시지를 시험지 포맷으로 푼 A/B용 변형판.
0~1.3s는 무음 표지 포스터(썸네일), 1.3s에 드럼 첫 강박과 함께 문 1이 시작되고 이후 문항마다 비트 5개.

|---|---|---|

| 8.2–11.6s | q2 | 2. 법학을 전공하려면 일을 그만둬야 한다. O / X → X → 해설: 퇴근 후 100% 온라인, 오프라인 수업 0회 |
